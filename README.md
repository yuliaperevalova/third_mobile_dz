## Описание проекта

Мобильное приложение для просмотра информации о фильмах студии Ghibli. Приложение позволяет просматривать список фильмов, детальную информацию о каждом фильме, добавлять фильмы в избранное и управлять списком избранных фильмов.

---

## Используемый API

### Studio Ghibli API
- **Название:** Studio Ghibli API (ghibliapi.vercel.app)
- **Описание:** Бесплатный REST API, предоставляющий информацию о фильмах, персонажах, локациях и других ресурсах студии Ghibli. API не требует аутентификации и ключей доступа.
- **Документация:** https://ghibliapi.vercel.app/
- **Base URL:** `https://ghibliapi.vercel.app/`

**Что предоставляет API:**
- Список всех фильмов студии Ghibli
- Детальная информация о каждом фильме (название, описание, режиссер, продюсер, дата выхода, рейтинг и т.д.)
- Информация о персонажах, локациях, видах и транспорте из вселенной Ghibli

## Скриншоты приложения

### 1. Экран загрузки (Loading)
*Скриншот экрана со списком фильмов в состоянии загрузки (CircularProgressIndicator)*

### 2. Экран ошибки (Error)
*Скриншот экрана с сообщением об ошибке и кнопкой "Retry"*

### 3. Список фильмов (List)
*Скриншот главного экрана со списком всех фильмов Studio Ghibli с возможностью pull-to-refresh*

### 4. Детальный экран (Detail)
*Скриншот экрана с детальной информацией о выбранном фильме (название, описание, режиссер, продюсер, дата выхода, рейтинг)*

### 5. Экран избранного (Favourites)
*Скриншот экрана со списком избранных фильмов (может быть пустым или содержать фильмы)*

---

### ⭐ Бонусные функции

- [x] **Экран Favourites как отдельный route**
  - Отдельный экран для просмотра избранных фильмов
  - Навигация через отдельный route `favourites`
  - Синхронизация состояния избранного между экранами
  - Отображение пустого состояния, когда нет избранных фильмов

- [x] **"Pull to refresh" / кнопка Refresh**
  - Реализован SwipeRefresh для обновления списка жестом "потянуть вниз"
  - Кнопка Refresh в TopAppBar для ручного обновления
  - Оба способа вызывают принудительное обновление данных (`forceRefresh = true`)

- [x] **Кэш последнего результата в памяти**
  - In-memory кэширование в `GhibliFilmsRepository`
  - При повторном запросе без `forceRefresh` возвращаются закэшированные данные
  - Кэш используется для быстрого доступа к фильму по ID без дополнительного сетевого запроса
  - Данные сохраняются в памяти на время жизни приложения

## Технологический стек

- **Язык:** Kotlin
- **UI Framework:** Jetpack Compose
- **Архитектура:** MVVM
- **Навигация:** Navigation Compose
- **Сетевые запросы:** Retrofit 2.11.0
- **HTTP клиент:** OkHttp 4.12.0
- **Логирование:** HttpLoggingInterceptor
- **DI:** Manual Dependency Injection (AppModule)
- **Асинхронность:** Kotlin Coroutines + Flow
- **Material Design:** Material 3
- **Pull-to-Refresh:** Accompanist SwipeRefresh
